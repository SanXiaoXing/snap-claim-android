验收： 火车 1 + 飞机 1 + 酒店 1 + 用车 1 = ¥1,653 + 差补 ¥200 = ¥1,853。点保存→ 落本地 SQLite → 历史可查/分享/二次编辑。

典型使用流程（出差 4 天）

  1. ① 出差前：打开 App → 「采集」Tab → 点 FAB「+」选「新建」→ 空报销单建好
  2. ② 抵达酒店：前台办理入住时让对方发 etrip 确认函 → 扫 QR → 自动添加酒店记录
  3. ③ 每次用车：上车前扫滴滴/曹操二维码 → 自动添加用车记录（带里程）
  4. ④ 坐飞机：值机前扫航司确认函 → 自动添加飞机记录
  5. ⑤ 漏了高铁：App 顶部黄条提示「还差高铁」→ 点 FAB 选「拍照」→ 拍 12306 票面 → ML Kit 识别车次/起止站/金额
  6. ⑥ 误加/多加：记录卡上右滑 → 露出红色删除按钮 → 点击删除 → 底部 Toast 3 秒内可「撤销」
  7. ⑦ 完工：切到「记录」Tab → 检查 4 类小计 + 合计 + 中文大写 → 点「保存」→ 落本地数据库（可查可分享可二次编辑）
